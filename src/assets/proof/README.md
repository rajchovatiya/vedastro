# Client proof screenshots

**Put review / spell-result screenshots in:  `assets/images/proof/`  (repo root, NOT this folder).**

The "Real Reviews From Real Clients" section auto-picks up every image in that
folder — `.jpg` / `.jpeg` / `.png` / `.webp`. Just drop files in; no code change.
Spaces / parentheses in filenames are fine. `.heic` is not — save as `.jpg`.

Blur personal info (phone numbers, full names) before adding.
